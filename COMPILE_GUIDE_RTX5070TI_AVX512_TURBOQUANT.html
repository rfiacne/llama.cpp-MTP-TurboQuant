6. 运行指南

6.1 llama-server 启动脚本

保存为 run_server.bat：

batch 
@echo off
setlocal enabledelayedexpansion

REM ===== 配置区 =====
set MODEL=..\models\Qwen3.6-27B-Q4_K_P_mtp.gguf
set CUDA_SCALE_LAUNCH_QUEUES=4x
set CONTEXT_SIZE=64000
set BATCH_SIZE=2048
set UBATCH_SIZE=512
set GPU_LAYERS=99
set NUM_PARALLEL=2
set NUM_THREADS=8

REM ===== 检查模型文件 =====
if not exist %MODEL% (
    echo [ERROR] Model file not found: %MODEL%
    echo Please download a MTP-enabled GGUF model
    pause
    exit /b 1
)

echo ================================================
echo llama.cpp Server - RTX 5070 Ti + TurboQuant
echo ================================================
echo.
echo Configuration:
echo   Model: %MODEL%
echo   Context: %CONTEXT_SIZE% tokens
echo   Batch: %BATCH_SIZE%x%UBATCH_SIZE%
echo   Parallel requests: %NUM_PARALLEL%
echo   GPU layers: %GPU_LAYERS%
echo   MTP: enabled (turbo3)
echo.

REM ===== 启动服务 =====
.\bin\Release\llama-server.exe ^
    -m %MODEL% ^
    --spec-type mtp ^
    --spec-draft-n-max 2 ^
    -ctk turbo3 ^
    -ctv turbo3 ^
    -c %CONTEXT_SIZE% ^
    -b %BATCH_SIZE% ^
    -ub %UBATCH_SIZE% ^
    --n-gpu-layers %GPU_LAYERS% ^
    --host 0.0.0.0 ^
    --port 8080 ^
    --temp 0.7 ^
    --top-k 20 ^
    -np %NUM_PARALLEL% ^
    -fa on ^
    -t %NUM_THREADS% ^
    --metrics

pause

6.2 核心参数说明

参数值说明
--spec-typemtp启用 MTP 投机解码
--spec-draft-n-max2MTP 每步预测 2 个候选 token
-ctk / -ctvturbo3KV 缓存使用 TurboQuant 3-bit 量化
-c64000上下文窗口长度（根据显存调整）
-b / -ub2048/512批处理大小 / 上限
--n-gpu-layers99所有层加载到 GPU（完全加速）
-np2最多 2 个并行请求（可调整到 4）
-t8CPU 线程数（按 CPU 核心数调整）
-fa on-启用 FlashAttention

8. 常见问题排查

Q1: CMake 报错 "architecture 90 not supported"

  • 确保已安装 CUDA Toolkit 12.0 或更新版本
  • 检查 nvcc --list-gpu-arch 是否包含 compute_90
  • 临时解决：改为 -DCMAKE_CUDA_ARCHITECTURES=89（RTX 40 系架构），性能略低

Q2: 编译失败 "LINK : fatal error LNK1104"

  • 检查 Visual Studio 2022 是否完整安装，包括 MSVC v143
  • 清理旧的编译目录：rmdir /s /q build_5070ti_avx512_turboquant
  • 确保磁盘空间充足（需要 50GB+）

Q3: 运行时报 "no kernel image is available for execution"

  • 二进制编译架构不匹配，删除 build 目录后重新编译
  • 确认 NVIDIA 驱动版本 ≥ 553
  • 运行 nvidia-smi 检查 GPU 是否被正确识别为 RTX 5070 Ti

Q4: 推理速度远低于预期（仅 5-8 t/s）

  • 确认 --n-gpu-layers 99 在运行命令中存在
  • 运行 nvidia-smi dmon -s u 检查 GPU 利用率（应 ≥95%）
  • 关闭后台 CPU 密集型任务，设置电源模式为"最高性能"
  • 验证 MTP 已启用：查看日志中是否显示 spec_type: mtp

Q5: TurboQuant 不生效，显存占用未降低

  • 确认运行命令包含 -ctk turbo3 -ctv turbo3 参数
  • 检查模型兼容性：某些旧模型可能不支持 KV 缓存量化
  • 验证编译时 TurboQuant 已启用：检查 ggml-turbo-quant.c 是否被编译

Q6: AVX-512 未检测到或执行非法指令

  • 进入 BIOS 检查 "AVX-512" 选项是否启用（某些主板默认关闭）
  • 运行 PowerShell 脚本检查 CPU 是否真正支持 AVX-512
  • 若 CPU 不支持，改用 -DGGML_AVX512=OFF -DGGML_AVX2=ON 重新编译

Q7: MTP 模式无效或 llama-server 崩溃

  • 确认使用带有 MTP 头部的 GGUF模型（文件名通常含 -mtp）
  • 验证启动命令包含 --spec-type mtp
  • 检查日志中是否有 MTP 相关错误信息
  • 尝试降低 --spec-draft-n-max 至 1 进行测试

Q8: 编译时间过长

  • 首次编译需要 10-15 分钟是正常的（CUDA 内核编译耗时）
  • 安装 ccache 加速增量编译：choco install ccache
  • 使用 SSD 而非 HDD 存储编译文件
  • 可调整 -j 参数为 CPU 核心数的 1.5 倍来并行加速
